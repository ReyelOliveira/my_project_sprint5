# Projeto Sprint 5 - Análise de Veículos

Este aplicativo web foi desenvolvido com Streamlit para explorar um conjunto de dados de anúncios de venda de carros.

## Funcionalidades:

- Visualização de histograma da quilometragem (odometer)
- Visualização de gráfico de dispersão entre quilometragem e preço
- Interface interativa com caixas de seleção
- Análise visual rápida dos dados

## Pacotes utilizados:

- Python
- Streamlit
- Pandas
- Plotly Express
